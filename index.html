라파 수질 예측 알고리즘 — 4단계 하이브리드 파이프라인

물환경정보시스템(WEIS)·기상청(ASOS)·홍수통제소 데이터를 시공간 정렬하여 설명가능한 수질 예측을 수행합니다.

STAGE 01

공공데이터 다중 API 수집

WEIS 수질측정망(TOC, BOD, Chl-a, T-N, T-P)과 최근접 KMA ASOS 일자료·홍수통제소 유량 데이터를 위경도 기반으로 자동 매칭·병합합니다.

STAGE 02

수문·기상 피처 엔지니어링

3일·7일 누적강수량, 선행 무강우 일수(First Flush), 채수 간격(days_since_prev), 수온·일사량 상호작용, 계절 주기(Sin/Cos)를 생성합니다.

STAGE 03

LightGBM Walk-Forward 학습

미래 데이터 누수를 차단한 확장형 시계열 교차검증(TimeSeriesSplit)으로 학습하며, NSE·RMSE·수질등급 적중률을 동시 최적화합니다.

STAGE 04

TreeSHAP 원인 분해 & 경보

예측치 상승·하강을 유발한 핵심 기상·수문 변수의 기여도를 정량 분해하고 환경부 생활환경기준 등급 경보를 산출합니다.

# 연동 데이터: 수질DB + ASOS 일·시간 + 단기/중기예보 + 하수처리장/TMS + 수문운영
def build_hydro_features(wq_df, weather_df, fcst_df=None, target="toc"):
    weather_df = weather_df.sort_values("date")
    weather_df["rain_3d"] = weather_df["rain"].rolling(3, min_periods=1).sum()
    is_dry = (weather_df["rain"] < 1.0).astype(int)
    weather_df["dry_days"] = is_dry.groupby((is_dry == 0).cumsum()).cumsum()

    df = wq_df.sort_values("date").copy()
    df[f"{target}_lag1"] = df[target].shift(1)
    df["days_since_prev"] = df["date"].diff().dt.days
    doy = df["date"].dt.dayofyear
    df["sin_doy"] = np.sin(2 * np.pi * doy / 365.25)
    df["cos_doy"] = np.cos(2 * np.pi * doy / 365.25)
    return pd.merge(df, weather_df, on="date", how="left").dropna()

# Walk-Forward TimeSeriesSplit Cross Validation
